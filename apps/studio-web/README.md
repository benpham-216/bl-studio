# Studio Web

React, TypeScript and Vite application for the CMS working surface.

Add Mantine for fast application layout and accessible controls. Use TanStack Query for server state, React Hook Form plus Zod for forms, Orval for generated API clients, Storybook for reusable UI assets, Vitest for focused component logic and Playwright for critical lifecycle journeys.

Do not install dependencies until the initial frontend ADR pins supported versions and explains the role of each overlapping UI library.
